## Quick Start

1. copy .env.example .env
2. Edit .env file with your values
3. docker-compose up --build

## Tech Stack
- Backend: Django 4.2
- Frontend: React 18
- Database: PostgreSQL
- API: Django REST Framework
- Auth: JWT
